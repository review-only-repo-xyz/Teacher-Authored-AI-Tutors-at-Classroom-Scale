# Example teacher prompts

The three files in this folder are real teacher-authored prompts from the
study, one per prompt pattern, shared to illustrate what each pattern looks
like in practice. They were screened for personal information; none named a
person, school, or district, so the wording is reproduced as written (typos
included), with the screening noted per file. Feature codes shown in each
file header are the study's activity-level codes for that prompt.

The full set of 74 prompts is not shared, because prompt wording in
combination with subject and level could identify individual teachers.
Researchers interested in further examples of real teacher prompts may
contact the authors.

No student text of any kind appears in this package. The file
`../synthetic_transcripts.md` contains fully invented example dialogues,
labeled as such, to illustrate the transcript structure that the turn-level
coding operates on.
